# 快速开始指南

## 📦 项目已创建完成

项目位置: `E:\ai\MyModernApp`

## 🛠️ 所需工具

### 1. 安装 JDK 17+
- 下载: https://adoptium.net/
- 安装后验证: `java -version`

### 2. 安装 Android Studio
- 下载: https://developer.android.com/studio
- 安装时选择 "Android SDK" 和 "Android Virtual Device"

## 🚀 三种构建方式

### 方式一: 使用 Android Studio (推荐)

1. 打开 Android Studio
2. File → Open → 选择 `E:\ai\MyModernApp`
3. 等待 Gradle 同步完成（首次需要下载依赖，约 5-10 分钟）
4. 点击工具栏的绿色运行按钮，或 Build → Build Bundle(s) / APK(s) → Build APK(s)
5. APK 生成在: `app/build/outputs/apk/debug/app-debug.apk`

### 方式二: 使用命令行

```bash
# 进入项目目录
cd E:\ai\MyModernApp

# Windows
gradlew.bat assembleDebug

# Linux/Mac
./gradlew assembleDebug
```

### 方式三: 使用提供的脚本

```bash
# Windows
cd E:\ai\MyModernApp
build.bat
```

## 📱 安装到设备

### USB 连接
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 直接安装
将 APK 文件复制到手机，点击安装即可。

## ✨ 应用功能

- ✅ **首页**: 网格展示媒体内容，支持分类筛选和收藏
- ✅ **分类**: 8大分类（自然、城市、美食、科技等）

## 🎨 技术特色

- **现代架构**: MVVM + Repository + Hilt
- **UI框架**: Jetpack Compose (Material 3)
- **数据库**: Room
- **图片加载**: Coil
- **视频播放**: ExoPlayer
- **异步处理**: Kotlin Coroutines + Flow

## ⚠️ 注意事项

1. **首次构建慢**: Gradle 需要下载依赖，请耐心等待
2. **需要网络**: 下载依赖和加载示例图片需要网络连接
3. **最低版本**: Android 7.0 (API 24)
4. **开发环境**: 建议使用 Android Studio

## 🐛 常见问题

### Q: 构建失败 "SDK location not found"
A: 在项目根目录创建 `local.properties`:
```properties
sdk.dir=C\:\\Users\\YourUsername\\AppData\\Local\\Android\\Sdk
```

### Q: Gradle 下载太慢
A: 可配置国内镜像，修改 `build.gradle.kts` 中的仓库地址

### Q: 运行时图片无法加载
A: 检查网络权限和网络连接，图片来自 picsum.photos
